# 第 3 步：反复回到同一处危险（Claude，2026-10-14）

## 用户决定

- 「接着做还是叫 agent 都无所谓」：保命动作结束后，回去或叫 Agent 都可以接受。
- 「可以考虑交给 agent，因为后续一定不去的话……很多冒险就是危险的」：要不要冒险回到同一个危险里，由 Agent 决定；反射层不能替它定成「再也不去」。

## 为什么不能按次数

见 [decision-capability-20261014.md](decision-capability-20261014.md) 第 3 节：被打断 1–5 次，Decision 选「叫 Agent」的概率始终在 0.2 附近，次数根本不进入它的判断。用户之前也定过，不由程序按次数叫 Agent。

## 改法（`f8d5d23`）

- 保命动作结束后、问「接下来做什么」之前，取出最近两次被打断时记录下的位置（打断记录里标着 `decision_default_tool` 的条目）。
- 单独问 Decision：这次危险打断工作的地方，和上次回去之前被打断的地方，是不是大约同一处？只问地点，因为背包有没有变化它比不出来，试验 `bench/why-same-probe*.py` 里约为 0.5–0.8。
- 答「同一处」就交给 Agent，打断记录原样随交接带过去。不到两次、答不出或答案不合法，就照常问结果题，不叫醒 Agent。
- 空闲时的保命动作没有原工作，不问这道题。没有次数上限，也没有距离阈值，「大约同一处」由 Decision 判断。

离线（`bench/return-place-trial.py`，第 3 步两次真实运行的全部连续打断，每帧 2 种顺序）：

| 情况 | 「同一处」的概率 | 回答 |
|---|---|---|
| 真实的连续两次打断 | 0.84–0.95 | 全部答「同一处」 |
| 改成远处约 50 格 | 0.10–0.13 | 全部答「不是」 |
| 改成约 8 格外 | 0.40–0.65 | 两种都有（留给 Decision 判断） |

单元测试：`tests/unit/test_body_loop_return_place.py`，4 项。全量 2542 passed，exit 0。
