## 保命后回去：异步告诉 Agent（`2f7ab91`）

保命动作打断工作、Decision 选回去接着做时，工作照做，同时给 Agent 一条只含事实的消息：被什么打断、做了什么、结果、在哪、这份工作最近几次被打断的地点。

真实验证 `step3-water-claude2`（第 3 步灌水夹具）：96.7 秒上浮后回去接着干，事实发出；125.5 秒 Agent 醒来（它正在思考，晚了 29 秒），原话：「身体现在安全落到地面了……之前它是被卡在树冠里、头顶还泡着一格水，所以一直在『回到地表』的死循环里打转……现在在地面上重新找树。」随后它自己换了做法，在地面上找树、砍木头、合成，任务完成，没有死亡。

## 补测（三次运行 `step8-extra-claude1/2/3`，空闲、带生活档案、无任务；夹具 `bench/fixture-step8-extra*.py`）

| 项 | 结果 |

| 远程攻击 | **通过**：背包有弓箭，骷髅出现，选了 3 次射箭，射中并射死 |
| 跟随 | 档案只说「过去看看」时从不选；档案写「跟着他」时会选，但跟着 / 走过去 / 看向每帧来回换。原因和修法见下 |
| 寻找 | 中文档案下从不选；见下 |
| 不该换剑（反面） | 第三次才测成（前两次夹具问题：触发条件写错；白天僵尸被晒死）。反击因目标丢失结束、剑完好时，结果题出了「装备石剑再打一次」，2 次出现 2 次都选了，随后叫醒 Agent。换更好的剑本身无害，但「再打一次」打的是不存在的目标。原因：换装备选项只看手里是剑、背包有别的剑，不看失败是否和工具有关。**建议**只在工具坏了或结果说明工具不合用时出这个选项；涉及第 6 步定的范围，等用户定 |

### 正在跑的生活动作用自己的名字出现（`44f1958`）

生活动作在跑时，它自己的选项被拿掉，只剩「Keep doing the current life activity: `__reflex_look_at(pos=[…])`」。离线试验（`bench/life-running-trial.py`，3 次运行全部 97 个生活运行帧，每帧两种顺序，基线复现 97/97）：

| 正在跑的 | 原写法 | 用自己的名字、排第一 |
|---|---|---|
| 跟随场景里的跟着 / 走过去 / 看向（64 问） | 64 次全换成别的 | 60 次接着做 |
| 第 7 步看向 Visitor（110 问） | 108 次选待着（每 1.5 秒重新看一次的原因） | 110 次接着看 |
| 第 7 步回住处（18 问） | 18 次接着走 | 18 次接着走 |

和保命动作的做法一样。真实复测 `step8-extra-claude3`：跟随场景只在开头换过两次，之后一直走向他。

### 回住处、走向玩家的到达半径（`claude/agent-always-live` 最新提交）

到达半径 2 按方块格算，「在家」按实际距离 2 格算。角色停在离家 2.3 格，题还出「回住处」，每 1.5 秒重跑一次（`step8-extra-claude3`）。两者都改成半径 1（「退回安全处」本来就是 1）。

### 寻找为什么不选（`bench/seek-trial.py`）

同样的帧，中文档案：54 问全选待着；英文档案：寻找和待着各半，取决于选项顺序。换说法、挪到第一位都没有差别。Decision 读中文档案读不出「去找他」；英文时一半一半也合理，因为同一份档案的作息写着「白天在住处附近待着」，和「他不在时去找他」本来就冲突。**选项本身没问题，档案要用英文写**，和 §19 意图用英文写是同一个道理；以后 Agent 自己写档案时照此要求。没改代码。
